# Glossary

One-line pointers. Definitions are limited to what the cards say; follow the link for quotes.

**Acrolos** — six-island chain of inventors between the Specific Ocean and the Nidian Sea. → `../world/geography.md`
**Akashic coin / notes** — Thabbashite void-made currency and knowledge storage. → `../world/religion-and-gods.md`
**Arcanist** — trade; ritualists, wizards, lurkers, Thabbashites. → `../trades/arcanist.md`
**Arcanology** — the arcane profession/institutional field (Academy, Department, Branch in Clockman). → `../world/voidal-magic.md`
**Barduse** — a dragon-type and a name (Emperor Barduse). → `../peoples/seraphim-and-dragons.md`
**Bask** — bile-spewing dragon. → same
**Blade of Questionable Morality** — card subtype; Ignatius, Rudo, Eustace, Jo, Abram. → `../factions/factions-and-organizations.md`
**Clockman** — coastal city; Mau finance; criminals; cults. → `../world/geography.md`
**Demon Knight** — card subtype (Geiseric, Ipsighast, Merbegon). → `../characters/marduun-era.md`
**Direstock** — Imperial Army stronghold/castle; cannibal culture. → `../world/geography.md`
**Ecto-manipulator** — Arcanist profession. → `../world/voidal-magic.md`
**Elf (31f / 31v35)** — the Gearsmith people. → `../peoples/elves.md`
**Expedition** — the Lugubrian Council's delivery of a Living God. → `../world/set-storylines.md`
**Gearsmith** — trade; inventors, golems, majigs. → `../trades/gearsmith.md`
**Ghost** — banker-trade undead. → `../peoples/the-dead.md`
**Golem** — clay construct programmed with runes. → `../world/technology.md`
**Great Swords / Swords of Great Justice** — Marduun-era warriors. → `../characters/marduun-era.md`
**Housecats** — the Marmothoan Empire's term for Mau. → `../peoples/mau.md`
**Imperial Army / Counter-Imperial Army** — rival armies. → `../world/society-law-and-money.md`
**Kaiser** — card subtype (Leo-, Tiger-, Panther-). → `../world/technology.md`
**Lesser Mau** — a Mau grouping in Goru-Goru Gidea and in Padamose's dislikes. → `../peoples/mau.md`
**Lingamite** — faction in the war; monks; descendants. → `../peoples/humans-and-others.md`
**Living God** — a voidal font worshipped by Thabbashites. → `../world/religion-and-gods.md`
**Lugubria** — blighted region of arcanists and monsters. → `../world/geography.md`
**Luridia** — a world/region name used broadly. → `../world/geography.md`
**Luteoderm** — armor/suit/giant item family. → `../world/technology.md`
**Majig** — card subtype for constructed devices/beings. → `../world/technology.md`
**Marduun** — fallen capital; also a book title. → `../world/timeline.md`
**Marmothoa / Marmothoan Empire** — former empire. → same
**Mau** — the banker people. → `../peoples/mau.md`
**Micromajig** — mass-produced half-foot majig; controversial. → `../world/technology.md`
**Moola** — slang for money. → `../world/society-law-and-money.md`
**Mud whisperer** — Gearsmith profession. → `../world/voidal-magic.md`
**Necromorph** — resurrected dead. → `../peoples/the-dead.md`
**Node** — majig/network component. → `../world/technology.md`
**Obsession / Greed / Elitism / Deception / Rage** — staple resource names. → `../trades/universal.md`
**Pluck** — card subtype; Pluck, Cheats, Abram, Bottlebeard, Mr. Fetch. → `../characters/unlikely-heroes.md`
**Quotidian** — modifier for ritual-based magic. → `../world/voidal-magic.md`
**Ritualist** — Arcanist profession. → same
**Sarcophyle** — Rogue people tied to blood/conversion. → `../peoples/sarcophyles.md`
**Sarume** — small dragon type; Chum. → `../peoples/seraphim-and-dragons.md`
**Seraphim** — dragon-type named characters. → same
**Shriever** — dragon type. → same
**Thabbashite** — desert-tribe worshippers of Living Gods. → `../peoples/thabbashites.md`
**Void / voidal** — source of magic and pollution. → `../world/voidal-magic.md`
**Voidal Humour** — raw magic substance, also a currency. → same
**Witch clock** — portable ritual casting device, usually illegal. → same
